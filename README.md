# tt-fdk

Vereinsprojekt: kostengünstige Alternative zum [TT-Planer](https://www.tt-planer.de/) für die
Organisation von Spielterminen, Rückmeldungen und Aufstellungen im Tischtennisverein.

## Stand

Noch kein Code — aktuell Recherche- und Entscheidungsphase.

## Dokumente

- [docs/recherche-tt-planer.md](docs/recherche-tt-planer.md) — Recherche zum TT-Planer
  (Funktionsumfang, Preise, Funktionsweise), zum Datenumfeld (click-TT / nuLiga / myTischtennis),
  zu Alternativen (kommerziell, kostenlos, Open Source), Kostenvergleich und
  Architekturvorschlag für eine Eigenlösung.
